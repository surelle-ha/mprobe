# Wordlist notice

The first-name and last-name data files were retrieved from the [`kkrypt0nn/wordlists`](https://github.com/kkrypt0nn/wordlists/tree/main/wordlists/names) repository, as requested for this project:

- `fname.txt` derives from `wordlists/names/names.txt`.
- `lname.txt` derives from `wordlists/names/top_family_names_usa.txt`.

The upstream repository did not declare a license when these files were retrieved. Review the upstream terms before redistributing the data. The `petname.txt` and `role.txt` lists are maintained in this project.
